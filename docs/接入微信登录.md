# 接入微信登录（扫码登录）

> 本文档说明如何在业务工程中基于 flower-web-infrastructure 的三方登录 SPI 接入微信开放平台网站应用（扫码登录）。
> 依据设计文档：`docs/superpowers/specs/2026-08-16-social-login-design.md`

## 1. 前置条件

- 微信开放平台（open.weixin.qq.com）注册**网站应用**，获取 AppID / AppSecret
- 配置"授权回调域"为业务回调域名（如 `https://api.example.com`）
- 依赖：框架已内置 `httpx`，无需额外引入

## 2. 实现 WechatSocialPlatform

在业务工程中新建 `wechat_social_platform.py`：

```python
# 业务代码示例：wechat_social_platform.py
from urllib.parse import quote

import httpx

from web_infra.error import CommonErrorCode
from web_infra.security.social import SocialAccessToken, SocialUserInfo

WECHAT_AUTHORIZE_URL = "https://open.weixin.qq.com/connect/qrconnect"
WECHAT_TOKEN_URL = "https://api.weixin.qq.com/sns/oauth2/access_token"
WECHAT_USERINFO_URL = "https://api.weixin.qq.com/sns/userinfo"


class WechatSocialPlatform:
    """微信开放平台网站应用（扫码登录）适配器"""
    provider = "wechat_open"

    def __init__(self, app_id: str, app_secret: str) -> None:
        self._app_id = app_id
        self._app_secret = app_secret

    async def build_authorize_url(self, state: str, redirect_uri: str) -> str:
        params = {
            "appid": self._app_id,
            "redirect_uri": redirect_uri,
            "response_type": "code",
            "scope": "snsapi_login",
            "state": state,
        }
        query = "&".join(f"{k}={quote(str(v), safe='')}" for k, v in params.items())
        return f"{WECHAT_AUTHORIZE_URL}?{query}#wechat_redirect"

    async def exchange_token(self, code: str, redirect_uri: str) -> SocialAccessToken:
        params = {
            "appid": self._app_id,
            "secret": self._app_secret,
            "code": code,
            "grant_type": "authorization_code",
        }
        async with httpx.AsyncClient(timeout=10) as client:
            resp = await client.get(WECHAT_TOKEN_URL, params=params)
        data = resp.json()
        if "errcode" in data and data["errcode"] != 0:
            raise CommonErrorCode.AUTH_SOCIAL_TOKEN_FAILED.to_exception(message=f"微信换取 token 失败: {data}")
        return SocialAccessToken(
            access_token=data["access_token"],
            expires_in=int(data["expires_in"]),
            openid=data.get("openid"),
            raw=data,
        )

    async def fetch_userinfo(self, token: SocialAccessToken) -> SocialUserInfo:
        # 微信 sns/userinfo 接口需要 openid + access_token 双参数，二者均来自换取结果
        params = {"access_token": token.access_token, "openid": token.openid}
        async with httpx.AsyncClient(timeout=10) as client:
            resp = await client.get(WECHAT_USERINFO_URL, params=params)
        data = resp.json()
        if "errcode" in data and data["errcode"] != 0:
            raise CommonErrorCode.AUTH_SOCIAL_TOKEN_FAILED.to_exception(message=f"微信拉取用户信息失败: {data}")
        return SocialUserInfo(
            provider=self.provider,
            openid=data["openid"],
            unionid=data.get("unionid"),
            nickname=data.get("nickname"),
            avatar_url=data.get("headimgurl"),
            raw=data,
        )
```

> 说明：微信 `sns/userinfo` 要求 `openid` 与 `access_token` 匹配，二者均由 `exchange_token` 返回并在 `SocialAccessToken` 中携带，`SocialLoginService` 将换取结果整体传入 `fetch_userinfo`。

## 3. 注册与装配

```python
# 应用启动装配示例
import os

from web_infra.security.social import SocialPlatformRegistry, InMemorySocialBindingStore, SocialLoginService
from wechat_social_platform import WechatSocialPlatform

registry = SocialPlatformRegistry()
registry.register(WechatSocialPlatform(app_id=os.environ["WECHAT_APP_ID"],
                                        app_secret=os.environ["WECHAT_APP_SECRET"]))

social_login_service = SocialLoginService(registry, InMemorySocialBindingStore())
```

> 提示：多实例部署时，将 `InMemorySocialBindingStore` 替换为业务实现的 Redis/DB 版 `SocialBindingStore`。

## 4. Controller 编排（FastAPI 示例）

```python
# controller 片段示例（import 按业务工程实际补充）
import secrets

from fastapi.responses import RedirectResponse


@router.get("/auth/social/{provider}/authorize")
async def social_authorize(provider: str, redirect_uri: str):
    state = secrets.token_urlsafe(16)  # 业务自行保存 state（session/缓存）防 CSRF
    url = await social_login_service.generate_authorize_url(provider, redirect_uri, state)
    return RedirectResponse(url)


@router.get("/auth/social/{provider}/callback")
async def social_callback(provider: str, code: str, state: str, redirect_uri: str):
    # 校验 state 后：
    result = await social_login_service.login(provider, code, redirect_uri)
    if result.bound:
        return {"access_token": result.access_token, "user_id": result.user_id}
    # 未绑定：业务决定自动注册（用 result.user_info 建本地账号后调 bind）或引导绑定
    return {"need_bind": True, "user_info": result.user_info}
```

## 5. 多平台切换说明

框架默认提供 `demo` 平台（`DemoSocialPlatform`）；接入真实平台后，业务按 `provider` 选择注册的实现即可，`SocialLoginService` 无感知。绑定/解绑能力见 `SocialLoginService.bind` / `unbind`（已登录用户可绑定多个三方账号，一个三方账号仅能绑定一个本地用户）。
