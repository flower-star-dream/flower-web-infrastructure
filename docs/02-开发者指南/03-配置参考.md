# 配置参考

> 全量配置项字典。框架默认配置权威来源为包内 `web_infra/infra/config/application.default.yml`（本文件即其完整解读）。
> 覆盖优先级：**代码 dict > 环境变量 > 项目根 .env > 项目 application.yml > 框架默认**。
> 环境变量映射规则：`app.db.mysql.host` → `APP_DB_MYSQL_HOST`（点号转大写+下划线）。

---

### app.lock：分布式锁

```yaml
app:
  lock:
    enabled: false       # 默认关闭（对齐 ai/mongo/capacity 惯例）：不装配锁，create_app 不加配置即可启动
    type: redisson       # 分布式锁实现：redisson（默认，看门狗续期+可重入）/ redis（静态租约）
    cache_max_size: 10000  # 锁实例缓存上限（方案甲按 Key 复用实例）：超出按 LRU 淘汰最久未用
    redis:               # 未启用 cache.type=redis 时的独立 Redis 连接（锁复用 cache 客户端则无需配置）
      host: 127.0.0.1
      port: 6379
      db: 0
```

- `enabled`：默认 `false`，不装配锁（不强制 Redis）。需显式 `true` 并配置 Redis 客户端才启用。
- `type`：`redisson`（默认）/ `redis`；未注册 type 装配期快速失败（`ConfigError`）。
- `cache_max_size`：方案甲"同 Key 复用实例"的缓存上限（默认 10000），超出按 LRU 淘汰最久未用，防锁 Key 无限增长导致内存泄漏；`0` 表示不淘汰（不推荐）。
- `enabled=true` 但既无 `cache.type=redis` 又未配 `app.lock.redis` 时快速失败（`ConfigError`，提示配置 Redis 而非静默回落）。
- Redis 客户端优先复用 `cache` 组件（`cache.type=redis`），否则用 `app.lock.redis` 段独立连接。
- 装配结果挂 `app.state.distributed_lock`（统一锁工厂 `(key, lease_time) -> 锁`）。

### app.event：进程内事件总线

```yaml
app:
  event:
    enabled: false       # 默认关闭：事件总线默认不装配（对齐 ai/mongo/capacity 惯例），create_app 不加配置即可启动
    fail_fast: false     # 单监听器异常是否阻断其余（false=记录日志继续分发）
```

- `enabled`：默认 `false`，不装配事件总线（不挂 `app.state.event`，零开销）。需显式 `true` 才装配 `EventBus` 并挂 `app.state.event`（业务 `publish` / `publish_after_commit` 发布，监听器经 `@event_listener` 注册）。
- `fail_fast`：默认 `false`。`true` 时单监听器异常向上抛、阻断其余监听器；`false` 时记录 warning 日志继续分发（异常隔离）。
- `EventBus` 构造签名：`EventBus(*, fail_fast=False)`，`fail_fast` 由配置 `app.event.fail_fast` 注入。
- 与 MQ 边界：事件总线用于**服务内**解耦（进程内），MQ（`app.mq`）用于跨服务/跨实例通信。默认关闭，需业务显式开启。

## 6. 数据库（app.db）

| 配置项 | 默认值 | 说明 |
| ------ | ------ | ---- |
| `default` | `default` | 默认数据源名（推荐形态 datasources 下：唯一数据源自动取它，多数据源回落名为 `default` 者，不存在则报错） |

| `instances` | `{}` | 混合多数据源：每实例带 type 字段，如 `{audit: {type: mysql, database: audit_db}}` |
| `router.mapping` | `{}` | 租户→数据源显式映射 |
| `router.pattern` | `tenant_{tenant_id}` | 租户数据源命名模板 |
| `sqlite.path` | `:memory:` | SQLite 路径 |
| `mysql.isolation_level` | `DEFAULT` | 引擎级默认隔离级别（同上；datasources 形态下配置在数据源项上） |
| `mysql.host` | `127.0.0.1` | |
| `mysql.port` | `3306` | |
| `mysql.database` | `""` | |

| `mysql.check_hostname` | `true` | |
| `mysql.connect_timeout` | `10` | 秒 |
| `mysql.statement_timeout_seconds` | `0.0` | >0 时经 max_execution_time 约束 SELECT |

**三种形态（datasources 段非空时优先）**：

```yaml
app:
  db:
    # 推荐：命名数据源池（default 指向默认源，业务 db 无参取它、按名取 datasources.<name>）
    default: primary
    datasources:
      primary: { type: mysql, host: 127.0.0.1, database: demo, isolation_level: READ COMMITTED }
      audit:   { type: sqlite, path: ":memory:" }
    # 旧形态（兼容保留）：app.db.type + <type> 单源；app.db.instances 混合多源；app.db.mysql.instances 多租户独立库
```

## 18. 配置样例（生产推荐写法）

```yaml
app:
  name: order-service
  env: prod
  logging:
    level: INFO
    format: json
  capabilities:
    enabled: [pay]
  web:
    middlewares:
      auth:
        enabled: true
      idempotency:
        enabled: true
```
