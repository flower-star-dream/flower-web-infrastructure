# 快速开始

> 目标：10 分钟从零跑通第一个基于框架的 Web 服务（含一个业务接口、健康检查、统一响应）。
> 本文假设你已了解 Python 基础。完整安装选项与配置字典见 [使用说明.md](../使用说明.md) 与 [配置参考](./03-配置参考.md)。

---

## 1. 环境准备

- Python ≥ 3.10
- 建议在项目内创建虚拟环境（避免污染全局）：

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
# source .venv/bin/activate  # Linux/macOS
```

## 2. 安装

最小安装（核心能力，开箱即用，无需任何外部服务）：

```bash
pip install flower-web-infrastructure
```

> 按架构形态安装「安装即用」组合包：
>
> ```bash
> # 最小单体：核心 + MySQL/SQLite + Redis
> pip install "flower-web-infrastructure[min-monolith]"
>
> # 最小微服务：核心 + MySQL + Redis + Nacos + RocketMQ + MinIO
> pip install "flower-web-infrastructure[min-microservice]"
> ```
>
> 本地开发调试框架本身可用 `pip install -e ".[dev,min-monolith]"`。
> 全部可选能力：`pip install "flower-web-infrastructure[all]"`。

## 3. 最小工程

创建目录并放置三个文件：

```
my-app/
├── main.py            # 应用入口
└── application.yml    # 业务配置（可省略，框架有默认值）
```

### 3.1 入口文件 main.py

```python
from web_infra import create_app, Result, CommonErrorCode

# create_app 读取 application.yml / 环境变量 / 框架默认配置，自动装配组件
app = create_app({"app.name": "my-app"})


@app.get("/hello")
async def hello(name: str = "world"):
    return Result.success(data={"message": f"hello {name}"})


@app.get("/v1/orders/{order_id}")
def get_order(order_id: str):
    if order_id == "0":
        # 统一抛出业务异常：错误码 → HTTP 状态码 → 统一响应体
        raise CommonErrorCode.COMMON_NOT_FOUND.to_exception()
    return Result.success(data={"orderId": order_id, "amount": "19.90"})


if __name__ == "__main__":
    import uvicorn

    uvicorn.run(app, host="0.0.0.0", port=8000)
```

要点：

- `create_app()` 返回 FastAPI 实例，同时自动完成：全局异常处理、日志、健康检查、指标、中间件装配；
- 接口统一返回 `Result`（结构为 `code + message + data`），失败用 `错误码.to_exception()` 抛出，框架统一转成响应；
- 返回 `Result.success(...)` 时 HTTP 状态码为 200，`data` 为业务数据。

### 3.2 配置文件 application.yml（可选）

```yaml
app:
  name: my-app
  logging:
    level: INFO
```

不写配置文件也可以跑——框架带全量默认配置（见 [配置参考](./03-配置参考.md)）。

## 4. 运行与验证

```bash
python main.py
```

启动后：

| 地址 | 说明 |
| ---- | ---- |
| `http://localhost:8000/hello?name=flower` | 业务接口，返回 `{"code":"S0000","message":"ok","data":{...}}` |
| `http://localhost:8000/v1/orders/0` | 抛错示例，返回 `{"code":"E4-COMMON-000","message":"资源不存在","data":null}`，HTTP 404 |
| `http://localhost:8000/health/live` | 存活探针：`{"status":"UP"}` |
| `http://localhost:8000/health/ready` | 就绪探针：探测各组件连通性 |
| `http://localhost:8000/metrics` | Prometheus 指标（浏览器访问为 HTML 可视化页） |
| `http://localhost:8000/docs` | Swagger 接口文档（FastAPI 自带） |

## 5. 最小单体示例：接上数据库与缓存

安装 `[min-monolith]` 后，在 application.yml 中声明组件类型：

```yaml
app:
  cache:
    type: redis          # 内存版改 Redis，业务代码不变
  db:
    type: mysql
    mysql:
      host: 127.0.0.1
      port: 3306
      database: flower_app
      username: ${APP_DB_MYSQL_USERNAME:root}
      password: ${APP_DB_MYSQL_PASSWORD:}
```

代码中使用：

```python
from web_infra import create_app, provide_db_session, get_logger

app = create_app()
logger = get_logger(__name__)

@app.get("/db-check")
async def db_check(db=Depends(provide_db_session(app.state.db))):
    # session 生命周期（提交/回滚/关闭）由框架自动管理
    rows = await db.query_all("SELECT 1 AS ok")
    return Result.success(data=rows)
```
